# AgentTown · 代理小镇

**几个任务一起跑，抬头就知道谁在忙、谁出了错。**

终端开了好几个，日志一直滚。你只是想知道：测试开始了吗？刚才的错误属于谁？
AgentTown 把这些活动放进一张小镇地图：一个代理一个工位，状态变了，工位跟着变；点进去，就能看到最近发生的事。

![小镇中的四个工位与底部事件时间带；此图为合成示例回放](docs/images/town-overview.png)

### 一张地图，少翻几个终端

- **看进度**：规划、编写、测试、错误各有状态，不必从整屏日志里找最后一条。
- **找上下文**：点击工位或底部事件，展开消息、时间和相关文件名。
- **接自己的事件**：向本地 API 发消息，让脚本的执行状态出现在地图上。

它适合想给并行任务加一个可视化窗口的开发者。目前需要你主动发送事件，还不能自动读取 Codex 或 Claude 的原生日志。

### 在本机打开

准备 **Node.js 24 LTS** 与 npm（也支持 22.12+ 的 22 系列及 26+；不支持 23/25），然后运行：

```sh
git clone https://github.com/shenyangs/agent-town.git
cd agent-town
npm run setup
npm run doctor
npm run dev
```

浏览器打开 [http://127.0.0.1:4201](http://127.0.0.1:4201)，终端保持运行；结束时按 Ctrl+C。首次 setup 会联网安装依赖与测试浏览器，下载时间取决于网络。安装问题见 [使用手册](docs/usage.md)。

### 让地图动起来

1. 点击 **播放示例**，先看四个工位如何随合成事件变化。
2. 切到 **本地实时**，另开终端，在项目目录运行 `npm run observe`。
3. 脚本会真的运行单元测试。点击 **Atlas**，查看测试开始与结束的活动。

![实时事件进入 Atlas 工位后，可展开查看消息与相关文件](docs/images/live-workstation.png)

第一次接入不必写插件：把你的进程状态转换成 `POST /api/events` 请求即可。[字段和接入示例](docs/setup-and-api.md) 已放在文档中。地图展示收到的事件，不会替你执行或调度任务。

### 今天可以用到哪里

本地事件接收、SSE 更新和地图查看已经可运行；示例回放是合成数据，实时事件来源由发送方声明。没有模型调用，也没有真实九代理协作回放。事件只保存在内存，最多 500 条，重启清空；文件名仅展示，不读取文件。

### 想继续看代码或验证结果

本地构建、单元测试、浏览器流程和演示录屏已经在 macOS 通过；README 配图来自实际运行的应用。Windows / Linux 实机与全新机器完整安装尚未验证。所有服务仅监听本机，没有部署所需的账号与鉴权，请勿直接暴露到公网。

停止开发服务后，可自行运行：

```sh
npm run build
npm run test
npm run e2e
npm run demo
```
